# Castle Musou — Castle Fight + musou (1 на 1)

Версия на базе Castle Fight: здания выпускают толпы слабых бойцов (по 3 за цикл, до 100 на игрока),
а герой — сильный musou-боец: удерживайте ЛКМ/Пробел, чтобы бить по дуге, копите комбо (каждый 4-й удар — круговой финишер),
наполняйте шкалу Musou и жмите Q. Герой не бьёт здания: он расчищает путь вашей армии к замку.
Параметры — в `data.json` (`settings.swing`, `heroes`, `units`).

    npm install
    npm start        # http://localhost:3000

Render: отдельный Web Service с корнем `castle-musou` (Root Directory), Build `npm install`, Start `npm start`.
